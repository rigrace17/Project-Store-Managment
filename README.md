# Project-Store-Managment
The Project Store Management assignment is "opening a business in your community." I chose to make a Media store, because I love any and all types of Media (TV Shows, Books, etc)! I used different types of instance variables (String, double, int) to represent each class. I also used "super" to make the subclasses, such as the Book subclass,apart of the Media superclass. A multitude of questions will be asked to the user--where they will type their answer into the console--based on the type of Media they choose to purchase. However, the "name" and "genre" question will be asked no matter what type of Media the user is purchasing.
